01 THE LEARNING PATH

Start simple.
Go deeper.

Work through these stages in order, or jump in where you feel comfortable. These are suggested steps, not a record of completed coursework.

  1. STAGE 01 · FOUNDATIONS

    Get comfortable with the basics.

    Practice Python functions, collections, and reading data. Review vectors, matrices, probability, and derivatives as you need them.

    The Python Tutorial ↗

    Official Python documentation. Best if you already know a little programming.

    Try it: Read a CSV file and summarize a few columns.

  2. STAGE 02 · MACHINE LEARNING

    Learn what a model actually learns.

    Explore regression, classification, loss, and overfitting. Keep training and test data separate, and compare a model against a simple baseline.

    Google Machine Learning Crash Course ↗

    Concept explanations and exercises from Google.

    Try it: Train a small classifier and explain its mistakes.

  3. STAGE 03 · DEEP LEARNING

    Build a network from the inside out.

    Learn tensors, automatic differentiation, and training loops. Track validation performance rather than only training loss.

    PyTorch: Learn the Basics ↗

    An introduction to a complete machine learning workflow with PyTorch.

    Try it: Train an image classifier and inspect incorrect predictions.

  4. STAGE 04 · LANGUAGE MODELS

    Turn models into useful experiments.

    Explore tokenization, transformers, and pretrained models. Then study retrieval, evaluation, and the limits of generated answers.

    Hugging Face LLM Course ↗

    A course on language models and the Hugging Face ecosystem.

    Try it: Build a small text tool and test it on difficult examples.

02 MAKE IT YOUR OWN

Less collecting.
More creating.

Small, finished experiments teach more than an endless reading list. Pick one question, build something, and write down what you discover.

01 / EXPERIMENT

Keep a learning notebook.

Record the question, dataset, baseline, result, and one thing you would change. Keep the experiment small enough to reproduce.

02 / EVALUATE

Build a document Q&A demo.

Use public or synthetic documents, show supporting passages, and test questions with no answer. Never upload private data without permission.

Resource links open in a new tab. Hosted notebooks or model APIs may require an account or incur costs; check their terms before using them.
